PROYECTO FINAL - RUTAS DEL PAISAJE CULTURAL CAFETERO
======================================================

IMPORTANTE: EL ZIP INCLUYE UNA DEMO SINTETICA QUE FUNCIONA SIN DESCARGAR OSM.
NO PRESENTAR LOS DATOS DE DEMO COMO RESULTADOS REALES.

1) Crear entorno: python -m venv .venv
2) Activarlo:
   MAC: source .venv311/bin/activate
   WINDOWS PowerShell: .venv\Scripts\Activate.ps1
3) Instalar: python -m pip install -r requirements.txt
4) Pruebas: python -m pytest -q
5) App: python -m streamlit run app.py
6) Experimentos de prueba: python -m scripts.experimentos --modo demo --limite-s 5

PARA RED REAL:
1) python -m scripts.preparar_red_real
2) COMPLETAR y verificar los 40 lugares en datos/real/catalogo_plantilla.csv
3) python -m scripts.asociar_catalogo
4) revisar datos/real/alertas_nodos_lejanos.json
5) python -m scripts.generar_resultados_reales
6) python -m scripts.experimentos --modo real --limite-s 300
7) python -m streamlit run app.py  y seleccionar Modo REAL
8) Leer README.md y docs/INFORME_TECNICO_BORRADOR.md

No se ha descargado la red real ni se han inventado 40 coordenadas.
